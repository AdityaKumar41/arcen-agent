# Deploy the docs on Vercel

This documentation site is a standalone Next.js app inside the `docs` directory. Deploy it from your Vercel account by setting the project root to `docs`.

## Local preview

```bash
cd docs
npm install
npm run dev
```

Open the local URL shown by Next.js.

## Build locally

```bash
cd docs
npm run build
```

The Vercel build command is the same:

```bash
npm run build
```

## Vercel project settings

When importing the GitHub repository into Vercel:

| Setting | Value |
| --- | --- |
| Framework preset | Next.js |
| Root directory | `docs` |
| Install command | `npm install` |
| Build command | `npm run build` |
| Output directory | Leave as Vercel default for Next.js |

`docs/vercel.json` records the same basic commands so the project is self-describing.

<Callout type="check" title="Ready for Git deploy">
  After pushing this repository, import it in Vercel, choose `docs` as the root directory, and deploy. No Python app runtime is required for the docs site.
</Callout>

## Editing docs

Pages are MDX route files under `docs/app/docs`. Shared UI lives in `docs/components`, navigation lives in `docs/lib/navigation.ts`, and global styling lives in `docs/app/globals.css`.

Add a new page by:

1. Creating a `page.mdx` file under the route directory.
2. Adding the page to `docs/lib/navigation.ts`.
3. Running `npm run build` from `docs`.
