# Overview

Arcen Agent is a tool-calling AI agent with a terminal interface, messaging gateway, persistent memory, skills, model-provider plugins, scheduled jobs, and multiple terminal backends.

This documentation site is built from MDX and is ready to deploy from the `docs` directory on Vercel.

<Callout type="tip" title="Best first path">
  Start with the quickstart, then read the CLI or messaging gateway page depending on where you want to use Arcen first.
</Callout>

## What Arcen gives you

| Area | What it does |
| --- | --- |
| CLI and TUI | Interactive terminal sessions, slash commands, model switching, history, and streaming tool output. |
| Messaging gateway | Telegram, Discord, Slack, WhatsApp, Signal, Matrix, Email, SMS, webhook, and API server adapters. |
| Tools | Registry-backed tool discovery with toolsets, approvals, and platform-aware exposure. |
| Skills | Built-in and optional procedural instructions that can be loaded by slash command or setup. |
| Memory | Persistent session storage, full-text search, and pluggable memory providers. |
| Plugins | General hooks, model-provider profiles, memory providers, context engines, and image generation providers. |

## Repository shape

The main Python surfaces are at the repository root: `run_agent.py`, `model_tools.py`, `toolsets.py`, `cli.py`, and `arcen_state.py`. The terminal UI lives in `ui-tui`, the messaging gateway lives in `gateway`, and plugin surfaces live under `plugins`.

For implementation details, use the [architecture guide](/docs/developer-guide/architecture) and [core files reference](/docs/reference/core-files).
