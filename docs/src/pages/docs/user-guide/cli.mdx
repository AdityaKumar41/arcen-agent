# CLI and TUI

The CLI is the default way to use Arcen locally. It provides slash commands, model switching, session management, autocomplete, tool progress, and log access. The TUI is an Ink-based terminal interface that can replace the classic prompt-toolkit experience.

## Start a session

```bash
arcen
```

Useful commands:

| Command | Purpose |
| --- | --- |
| `arcen model` | Choose a provider and model. |
| `arcen tools` | Configure enabled toolsets. |
| `arcen setup` | Run the setup wizard. |
| `arcen doctor` | Diagnose local problems. |
| `arcen logs --follow` | Tail logs while testing behavior. |

## Slash commands

Slash commands are defined centrally in `arcen_cli/commands.py`. The CLI, gateway help, Telegram menu, Slack routing, and autocomplete all derive from the same registry.

Common commands:

| Command | Use |
| --- | --- |
| `/new` or `/reset` | Start a fresh conversation. |
| `/model [provider:model]` | Change model for the active session. |
| `/retry` | Retry the last turn. |
| `/undo` | Remove the last turn. |
| `/compress` | Compress conversation context. |
| `/usage` | Show context and usage details. |
| `/skills` | Browse or load skills. |

## TUI

Run the TUI with:

```bash
arcen --tui
```

or:

```bash
ARCEN_TUI=1 arcen
```

The process model is:

```text
arcen --tui
  Node Ink UI
    stdio JSON-RPC
  Python tui_gateway
    AIAgent, sessions, tools, slash commands
```

## Local TUI development

```bash
cd ui-tui
npm install
npm run dev
npm run type-check
npm test
```

<Callout type="tip" title="Thin route roots">
  TUI route roots should compose views and shell. Shared state belongs in nanostores near the feature or in `src/store`.
</Callout>
